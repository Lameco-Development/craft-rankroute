# Plan: text flow (text-only optimisation that cannot break a page)

Status: in progress, branch `feat/text-flow`.

## Problem

The optimizer flow exports the whole element, the model rewrites all of it and the import
rebuilds the page. `MatrixFieldHandler::import()` recreates every nested entry (`new1..N`),
link fields are exported as flat strings, and nothing stops the model from touching
non-text data. That is how buttons were lost. Goal: optimising a page must never change
buttons, links, images, forms or block structure.

## Approach

Craft extracts the text, the RankRoute backend only rewrites strings, Craft writes those strings back onto the
untouched structure. The old optimizer endpoints and legacy aliases stay as they are.

## Contract (the backend depends on this)

All endpoints need `Authorization: Bearer <RANKROUTE_API_KEY>`. Paths:

- `GET  /actions/rankroute/text/export?url=<url or path>` (or `?id=<elementId>&siteId=<id>`)
- `POST /actions/rankroute/text/import`
- `GET  /actions/rankroute/text/verify?draftId=<drafts.id>`

### Export response (200)

```json
{
  "element": {"id": 51, "siteId": 1, "type": "craft\\elements\\Entry", "url": "https://…", "cpEditUrl": "https://…"},
  "fingerprint": "sha256:…",
  "items": [
    {"id": "title", "type": "plain", "value": "Applicaties", "maxLength": null},
    {"id": "seo.seoTitle", "type": "plain", "value": "…", "maxLength": null},
    {"id": "seo.seoDescription", "type": "plain", "value": "…", "maxLength": null},
    {"id": "headerTitle", "type": "html", "value": "<p>…</p>", "maxLength": null},
    {"id": "pageBuilder[3].content", "type": "html", "value": "<p>… <a href=\"/x\">y</a></p>", "maxLength": null},
    {"id": "pageBuilder[6].items[1].title", "type": "plain", "value": "…", "maxLength": 255}
  ]
}
```

Errors: 400 bad input, 401 auth, 404 element not found. JSON body `{"error": "…"}`.

### Text item

- **Address** (`id`): dot path from the element. `title` is the element title,
  `seo.seoTitle` / `seo.seoDescription` are SEOmatic meta, `<fieldHandle>` is a custom field
  (layout instance handle), `<matrixHandle>[<n>]` is the n-th nested entry (0-based, counted
  over *all* nested entries in sort order, disabled included) and `.title` on a nested entry
  is its native title.
- **type**: `plain` (PlainText, native title, SEO meta) or `html` (CKEditor/Redactor).
- **maxLength**: PlainText `charLimit` when set, else `null`.

What becomes an item (all conditions):
- the field is PlainText, CKEditor (`craft\ckeditor\Field`) or Redactor, or it is a native
  title on an entry type with `hasTitleField` and no `titleFormat`, or SEOmatic
  `seoTitle`/`seoDescription` literal values;
- the value is non-empty after trim (empty stays empty: the model must not add content);
- the value is not a URL, e-mail address, number-only string, and does not contain Twig
  (`{{` or `{%`);
- the field handle does not match `excludeFields`, and no nested entry on the path has an
  entry type matching `excludeEntryTypes` (config below);
- the nested entry and all its ancestors are enabled.

Everything else (Link, Assets, relations, Dropdown, Lightswitch, Table, Forms, Matrix
structure, SEOmatic settings other than those two, nested CKEditor entries) is never an
item and never written.

Config (`config/rankroute.php`, optional, no settings UI), defaults:

```php
return [
    'textFlow' => [
        // case-insensitive fnmatch patterns on field handles
        'excludeFields' => ['*url', '*webhook*', 'importId', '*Id', 'llmContent', 'cocNumber'],
        // case-insensitive fnmatch patterns on nested entry type handles
        'excludeEntryTypes' => ['*button*'],
    ],
];
```

### Fingerprint

`sha256:` + hash of a canonical JSON document of the element's *structure and text*: element
id, siteId, typeId/fieldLayout uid, every field value serialised for comparison (see
Structure snapshot) and every text item `{id, type, value}`. Any edit to the element (text or
structure) between export and import changes it.

### Import request

```json
{"elementId": 51, "siteId": 1, "fingerprint": "sha256:…", "items": [{"id": "title", "value": "…"}]}
```

`url` may be given instead of `elementId`/`siteId`.

Validation, all-or-nothing, before anything is written:
1. element exists (404 otherwise);
2. `fingerprint` equals the current fingerprint → else **409** `fingerprint_mismatch`;
3. the set of submitted ids equals the set of current item ids exactly: unknown id →
   `unknown_id`, missing id → `missing_id`, duplicate → `duplicate_id`;
4. each value is a string, non-empty after trim (`empty_value`), within `maxLength`
   (`too_long`);
5. `plain`: no HTML tags allowed (`html_in_plain`);
6. `html`: the tag skeleton is identical (`html_structure_changed`): same sequence of opening,
   closing and void tags, same tag names, same attributes and attribute values (so identical
   `href`s). Only text between tags may differ. Entities are decoded before comparing text is
   irrelevant; comparing tags is what matters.

Any failure → **422** `{"success": false, "errors": [{"id": "…", "code": "…", "message": "…"}]}`
and nothing is written.

### Import behaviour

- No value differs from the current value → 200, `changedItems: []`, no draft.
- Otherwise create a draft (`Drafts::createDraft`, not provisional) of the element in that
  site, and write only the changed items:
  - element title / top-level fields: set on the draft;
  - nested entries: through Craft's delta Matrix format on the owner
    (`{entries: {<id>: {title?, fields: {…}}}, sortOrder: [<all existing ids>]}`), recursively,
    so every existing nested entry keeps its identity and only the targeted ones get a
    derivative; never `new*` keys;
  - SEO: load the draft's SEOmatic field value and set only `metaGlobalVars.seoTitle` /
    `seoDescription` (same mechanics as `SeoBulkService`).
- Save the draft, then run the **structure check** (canonical vs draft). If it fails, delete
  the draft and return **500** `structure_check_failed` with the diff.

Response 200:

```json
{
  "success": true,
  "elementId": 51, "siteId": 1,
  "draftId": 123, "draftElementId": 4567, "cpEditUrl": "…",
  "changedItems": ["title", "pageBuilder[3].content"],
  "structureCheck": {"passed": true, "differences": []}
}
```

### Structure check

`StructureSnapshot::build(element)` returns a normalised tree of everything except text
values:
- element attributes: typeId, fieldLayout uid, enabled (per site), slug, uri, postDate,
  expiryDate, authorIds, parent id, level;
- each field: Link → full serialised value (type, value, label, target, …); Assets/relations →
  ordered ids; options → value(s); Lightswitch/Number/Date/Table/other → serialised value;
  SEOmatic → full serialised settings with `seoTitle`/`seoDescription` removed; text fields →
  `{text: "plain"}` or `{text: "html", tags: <skeleton>}` (skeleton, not text);
- Matrix → ordered list of nested entries: `{canonicalId, typeId, enabled, fields…}` recursively
  (canonical id so a draft derivative compares equal to its source).

Text items that are *not* extractable (empty, URL, Twig, excluded) are compared as full
values, so they can never change.

`StructureCheck::compare(canonical, draft)` → `{passed, differences: [{path, before, after}]}`.
`GET text/verify?draftId=` runs it for an existing draft.

## Plugin components

- `services/text/TextAddress` – parse/format addresses.
- `services/text/HtmlSkeleton` – tag skeleton of an HTML string (DOM-free tokenizer, handles
  void tags, attributes in original order, entity-insensitive attribute values).
- `services/text/TextExtractor` – element → `TextItem[]` (+ internal locator per item: owner
  element, field handle or `title`/`seo.*`).
- `services/text/StructureSnapshot` + `StructureCheck`.
- `services/text/Fingerprint`.
- `services/TextExportService`, `services/TextImportService`.
- `controllers/TextController` (`export`, `import`, `verify`; API key; CSRF off; `status`
  lists new endpoints).
- `dto/TextItem`, `dto/TextExportResult`, `dto/TextImportResult`, `dto/StructureCheckResult`.
- `console/controllers/TextFlowController` – `rankroute/text-flow/smoke`: for every live
  element with a URI (option `--site`, `--limit`, `--uri`), over HTTP against the site's own
  base URL (option `--base-url`) with the API key: export → deterministic rewrite (plain: append
  " ✓" within maxLength; html: append " ✓" to the last non-whitespace text node of each block
  element) → import → assert `structureCheck.passed` → re-verify via `text/verify` → negative
  probes on the first N elements (changed href → 422, missing id → 422, stale fingerprint →
  409) → delete the draft unless `--keep-drafts`. Prints a table and exits non-zero on any
  failure.
- Tests: unit (address, skeleton, validation), integration with CKEditor installed as dev dep
  (fixture: nested Matrix 3 levels deep, button entry type with Link, CKEditor with `<a href>`,
  Assets, Dropdown, SEOmatic): export shape, import writes only targeted strings, nested
  entry ids preserved, structure check passes, every rejection path.

The n8n flows are replaced by a Laravel app in a separate repo, `~/Sites/rankroute`
(spec: `docs/plans/2026-09-16-backend.md` in that repo). It is the only client of the text
endpoints above. The n8n flows keep running for the beta customers on the old endpoints until
each site is moved over.
